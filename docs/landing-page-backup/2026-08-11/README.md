# Landing page backup — 2026-08-11

This directory contains the exact homepage-related files as they were before the 2026 landing page redesign.

To restore the previous presentation, copy the contents of each `.txt` file back to the matching source path documented below:

- `_index.tsx.txt` → `app/routes/_index.tsx`
- `header.tsx.txt` → `app/components/header.tsx`
- `footer.tsx.txt` → `app/components/footer.tsx`
- `app.css.txt` → `app/styles/app.css`

The backup intentionally sits outside Remix's route and component directories so it cannot affect the running application.
